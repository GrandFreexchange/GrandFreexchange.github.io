Tile map

North is up. Each square is one game tile, with a darker line every 8 tiles.

How to import into RuneLite

  1. In RuneLite, open the plugin list and make sure Ground Markers is on.
  2. Copy a tile pack with its Copy button.
  3. In game, right-click the world map orb next to the minimap and choose Import Ground Markers.
  4. Say Yes when it asks to import the markers. They appear as soon as you are in that area.

No Import option on the orb? In the Ground Markers settings, turn on Show import/export/clear options. Importing adds to the markers you already have. Clear on the same menu removes the markers in the area you are standing in.
